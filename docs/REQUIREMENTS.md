# 需求与项目范围

本文记录已确认的目标及项目自行制定的验收范围。用户没有正式任务书，本文不是教师提供的评分标准。

## 已确认事项


| 项目       | 约定                                                    |
| ------------ | --------------------------------------------------------- |
| 目标       | 使用电脑摄像头识别本人，匹配时显示登记昵称              |
| 算法路线   | 使用预训练 CNN 提取人脸特征，通过特征距离判断是否为本人 |
| 参考与依赖 | 以 DeepFace 为基础实现识别流程，第一版无需训练或微调    |
| 当前开发机 | Windows、Python 3.12、GTX 1060 3GB，无摄像头            |
| 最终演示机 | RTX 4070 移动版，带摄像头；具体运行环境待核实           |
| 运行设备   | 兼容环境下优先使用 GPU，保留 CPU 运行方式               |
| 协作方式   | 按任务分配独立分支和 worktree，主聊天负责集成           |

## 第一版功能

### 本人注册

- 从指定文件夹读取本人照片，建立一个昵称对应的本地特征库。
- 每张注册照片必须恰好检测到一张脸；无脸、多脸或无法读取时明确报告文件与原因。
- 同一昵称允许多张照片。重新注册以整库替换为单位，失败时保留原库。
- 注册仅提取并保存特征，不更新预训练模型权重。

### 图片识别

- 读取一张本地图片，与注册库进行比对。
- 恰好一张脸且达到匹配条件时显示昵称；恰好一张脸但不匹配时显示“未知”。
- 无脸和多脸分别返回明确状态；第一版多脸画面不执行身份判定。
- 输出人脸框、距离、阈值与处理耗时。距离不是概率，不显示为“身份置信度百分比”。

### 视频与摄像头

- 本地视频与摄像头复用图片识别逻辑。
- 显示当前帧的状态、可用的人脸框和昵称，支持正常退出。
- 无摄像头、设备被占用、视频不存在或读取失败时给出中文提示，并释放已打开的资源。
- 当前电脑先用图片和视频验证，最终在 4070 电脑上验证真实摄像头。

### 执行设备

- 提供自动、CPU 和 CUDA 三种选择，启动时报告实际配置及验证结果。
- 自动模式允许回退到 CPU，回退原因应可见。
- 显式选择 CUDA 时，若无法确认模型使用 GPU，则报错退出，便于验收。
- 识别性能在目标机实测，当前不承诺固定帧率或加速倍数。

## 第一版边界

优先交付单个已登记身份、单人画面的本地识别工具。多身份管理、多人同时识别、活体检测、训练与微调、Web 服务及数据库管理属于后续扩展。

## 数据与实验

- 使用本人照片注册；用于测试其他人的图片或视频应取得相应使用许可。
- 注册、阈值调整、最终测试分别采集；同一照片及其裁剪、增强版本保持在同一集合。
- 同一连续视频的相邻帧按拍摄会话整体归属，避免把相邻帧拆到注册和测试中。
- 调整阈值后再运行最终测试，记录识别成功、误拒、误识和检测失败的原始计数。
- 人脸数据、特征库、模型权重和运行结果保存在本地忽略目录；代码和复现说明纳入 Git。

# 开发计划

## 当前状态

已确定课程要求自行搭建和训练 CNN。当前只建立项目基线，尚未创建任务 worktree 或实现算法。

## 开始并行前

主聊天先与用户确认课程任务书、数据集、CPU/GPU 条件和演示形式，然后提交共享约定：

- 数据目录结构、身份标签映射、划分清单、图像尺寸和归一化方式。
- 模型输入输出、类别数、训练配置与 checkpoint 格式。
- 评估指标和可运行的验收命令。

第一版优先完成本地图片的已登记身份分类，形成“数据 → CNN → 训练 → 评估 → 推理”闭环。

## 建议任务边界

| 任务 | 建议分支 | 文件范围 | 验收方向 |
| --- | --- | --- | --- |
| 数据处理 | `feat/data` | `src/cnn_face/data.py`、相关测试 | 可复现划分、标签映射、预处理 |
| CNN 与训练 | `feat/cnn` | `src/cnn_face/model.py`、`src/cnn_face/train.py`、相关测试 | 前向传播、短训练、保存与加载 |
| 评估与推理 | `feat/evaluation` | `src/cnn_face/evaluate.py`、`src/cnn_face/predict.py`、相关测试 | 指标计算、单图预测 |

评估与推理可在模型接口确定后开展；依赖尚未满足时先串行完成共享基础。

主聊天统一修改公共入口、依赖声明和共享约定，避免多个 agent 同时调整这些文件。完成每个分支后先审查并运行相关检查，再逐个合并到 `main`，最后进行端到端验证。

任务 worktree 建议位于本仓库之外、与本目录同级；每个 worktree 使用独立分支和虚拟环境。共享数据时在任务配置中使用明确的数据路径。

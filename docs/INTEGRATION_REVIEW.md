1. 公共入口尚未接通 enroll、recognize、stream，无法通过命令完成闭环；属于预留集成职责，按既定接口补齐。

3. Windows 默认 GBK 可能无法读取带中文注释的 UTF-8 锁文件；安装说明统一设置 PYTHONUTF8，不更改锁定依赖。
4. 文档仍将已交付模块标为待实现；集成验证后同步状态、命令和实际限制。
